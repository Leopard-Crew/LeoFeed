# LeoFeed Skeleton Build Test

The initial LeoFeed Cocoa skeleton builds on the target Leopard/PPC system.

Test system:
- Mac OS X 10.5.8 Leopard
- PowerPC G5
- Xcode 3.x
- Apple GCC 4.2.1
- SDK: macosx10.5

Result:
- LeoFeed.xcodeproj builds as a PPC Cocoa application.

Rule:
The LeoFeed skeleton is independent from the Vienna vendor project.
Vendor remains read-only reference material.
